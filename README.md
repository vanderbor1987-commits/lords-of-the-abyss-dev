# Lords of the Abyss

## Arena live-player leaderboard

The Arena uses the platform's free built-in leaderboard; it does not require a game server.

- **Yandex Games:** in the developer console, create a numeric leaderboard with technical name `arena_trophies`, sorted by score descending. Arena saves submit the player's trophies to this board. Open **Arena → Ladder → Live Players** to view the platform rankings.
- **VK:** the Arena opens VK's native leaderboard for the current player. It submits Arena trophies as the score; VK controls who can see the board.
- The leaderboards are platform-specific and contain scores only. Arena fights continue to use the existing in-game opponents. Standalone/GitHub Pages has no shared player leaderboard.
